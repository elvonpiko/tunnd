What you can tunnel

Anything that speaks HTTP or TCP.

One binary, three shapes. Streaming responses and WebSockets pass through untouched.

HTTP apps

Express, Vite, Django, Rails — a public HTTPS URL in seconds. SSE and long streams are forwarded with flushes preserved.

tunnd http 3000

WebSockets

HMR, chat, live dashboards. A wss:// URL for the same port — REST keeps working alongside it.

tunnd ws 3000

Raw TCP

Postgres, Redis, SSH — anything that speaks bytes. A public port is allocated from the server's range.

tunnd tcp 5432
Self-hosted

Up and running in under a minute.

One VPS, one DNS record, one command. Then never pay a tunnel bill again.

1

Run the server on your VPS

Add a wildcard DNS record (*.tunnd.yourdomain.com → vps-ip), then run one command. It installs the binary, requests a Let's Encrypt certificate, and starts a systemd service.

curl -fsSL https://raw.githubusercontent.com/elvonpiko/tunnd/main/setup.sh | sudo bash

Prefer Docker, your own certificate, or running behind Caddy? See the deployment guide.

2

Install the client and tunnel

One command on macOS, Linux, or Windows. Run tunnd setup once to point at your server and paste the token from your dashboard.

curl -fsSL https://raw.githubusercontent.com/elvonpiko/tunnd/main/install.sh | bash
tunnd setup
tunnd http 3000
iwr -useb https://raw.githubusercontent.com/elvonpiko/tunnd/main/install.ps1 | iex
tunnd setup
tunnd http 3000
