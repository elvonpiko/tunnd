What you can tunnel

Anything that speaks HTTP or TCP.

One binary, three shapes. Pick yours.

HTTP / HTTPS apps

Express, Vite, Django, Rails, anything. Get a public HTTPS URL in seconds. Streaming and SSE responses pass through with flushes preserved.

tunnd http 3000

WebSockets

HMR, chat, live dashboards. HTTP upgrades pass through transparently — no flags, no config.

tunnd http 3000 # /ws works

Raw TCP

Postgres, Redis, SSH, anything that speaks bytes. Public TCP port allocated automatically.

tunnd tcp 5432
Self-hosted

Up and running in under a minute.

One VPS, one DNS record, one command. Then never pay a tunnel bill again.

1

Run the server on your VPS

Add a wildcard DNS record (*.tunnd.yourdomain.com → vps-ip), then run one command. Installs the binary, requests a Let's Encrypt cert, starts a systemd service.

curl -fsSL https://raw.githubusercontent.com/elvonpiko/tunnd/main/setup.sh | sudo bash

Prefer Docker, custom TLS, or running behind Caddy? See the deployment guide.

2

Install the client and tunnel

One command on macOS, Linux, or Windows. Run tunnd setup once to point at your server and paste your auth token from the dashboard.

curl -fsSL https://raw.githubusercontent.com/elvonpiko/tunnd/main/install.sh | bash
tunnd setup
tunnd http 3000
iwr -useb https://raw.githubusercontent.com/elvonpiko/tunnd/main/install.ps1 | iex
tunnd setup
tunnd http 3000
